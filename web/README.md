# ModalityOps workbench

A React/TypeScript interface for the Python acquisition-QC engine. See the repository README for the complete local workflow.

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm build:static
```

The standard static build emits `out/`, served by FastAPI in the full local installation. It also works on GitHub Pages with `NEXT_PUBLIC_BASE_PATH=/modalityops`.

The alternative `pnpm build` command emits a Vinext static build for the hosted handover. Its deployment metadata and build helpers are infrastructure, not a runtime dependency of the Python service. The project does not require sign-in or an API key.

The dashboard validates imported reports, shares a cursor across min/max trace summaries, and exposes raw/reference time, clock evidence, channel metrics and hashed provenance. Five precomputed synthetic reports are generated by `../scripts/export_demo.py`. A same-origin `/api/v1/health` response enables fresh analyses with the local backend.

Reusable interface primitives retain their upstream licenses. Product code lives in `app/page.tsx`, `app/globals.css` and `lib/report.ts`.
